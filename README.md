# 园丁计划

系统演化的时间维度。2026-10-20 定稿，副题「农书」。

> 题签引语：园丁只管浇水修剪，花自己开。

> 首发存档：Zenodo（2026-10-19）｜DOI [10.5281/zenodo.23478345](https://doi.org/10.5281/zenodo.23478345)

## 讲什么

七篇：审时（涌现有无与强弱）／器具（三件套）／月令（何时宜涨、何时宜剪、何时宜休耕）／验田（实证线）／收成（预报服务）／疆界（与各家之界）／地力（界限与待实证）。每篇循三段而记：先一句机制，再讲怎么操作，末了讲怎么证伪。

核心是把「涌现」从结果名词改成过程动词——立要素、参数、指标三事，给最小完备度的五参数组合判定；参数未齐即如实报「未触发」，不承诺周期。

另有一处，是把数值天气预报的「预报、实况、校准、再预报」闭环移入生态演化，并以四象限核算法给预报定价，使预警之值可计量。

## 名字

书名作《园丁计划》，副题「农书」。仓库名取英文 **gardener**。

取 gardener 而不取拼音 yuandingjihua，两个理由：一是与「园丁只管浇水修剪，花自己开」的题签相合，英文一词有画面；二是短，且与账号下既有的英文缩写库（LBAF、SCION、TAF）不冲突。

## 与他三件的关系

| 简称 | 书名 | 关系 |
|---|---|---|
| 《架构》 | 内核旋钮架构 | 单主体内部怎么搭，本书不论 |
| 《协议》 | MCP 控制层协议规范 | 模块怎么连，本书不论 |
| 《主篇》 | 拼好模主篇 | 多主体怎么治，本书不论 |

本书与三者正交无重叠：它只管「随时间怎么变」。凡涉机制本体处，只引不复述。

## 记号六则

〔已立〕已有正文；〔已实证〕有实验支撑；〔待标定〕有值待真实数据校准；〔待补〕源件所无；〔待锚〕外部锚未核出处；〔已锚〕外部锚出处已核。

全书以此自标完成度，不把待补说成已立。
